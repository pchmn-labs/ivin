# Project

What the design adds to the [glossary](../../GLOSSARY.md)'s terms in the `project` module, on the server and in the UI. The design shared by every module is in [the architecture](README.md).

- The open projects, their order, the selected project, the tabs, their order and each project's selected tab are stored in SQLite and restored at launch.
- Trust is stored per folder, by its real path, in SQLite beside the projects; the projects saved before trust existed were trusted by the migration that added it. `project.open` fails with `ProjectNotTrusted` unless the folder is inside a trusted project, or the call carries `trust`, which stores the trust first; the UI answers that failure with the trust dialog and calls again with `trust`. Whether a folder is inside a trusted project (`FolderTrust`) is read from the files alone, with no git command: the folder is inside a trusted folder, or the `.git` file of a worktree made outside ivin points at a repository whose checkout is. The server checks it before every git command (in the `Git` adapter) and before starting a session's agent, which then fails with the reason in its transcript. See [ADR-0010](../adr/0010-ivin-asks-the-user-to-trust-a-project-folder-before-running-git-or-an-agent-in-it.md).
