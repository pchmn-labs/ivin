# Design references

`app-shell-prototype.html` is the HTML prototype the milestone 1 redesign (#33) was settled on. It is a single file with fake data: open it in a browser, no server needed. `DESIGN.md` is the design of record; the prototype is a reference for what it shows beyond the app.

What the prototype shows that the app does not have yet:

- Tabs in the main title bar, with the PR icon and its checks.
- The status line under the composer: worktree, branch, PR checks, background tasks, context usage and cost.
- Effort and permission mode beside the model.
- The question sheet with numbered options, and the "?" mark on a session waiting on a question.
- The background-task dot on the session mark, and "In background" on a tool row.
- Tool durations.
- The inactive sessions group.
- The column sidebar view and the letter project icons (press `V` to switch the view, the floating switch for the icons).

The app departs from it on purpose in a few places: Thinking is hidden, an allowed approval leaves no line in the transcript, and the projects sit in a bar at the bottom of the sidebar card.
