# files

The Files tab of the sidebar, in the `sidebar.panel` slot (contribution `files/panel`, titled "Files"): a tree of the working folder of the session on screen, which follows it when another session comes on screen. Above the tree, a row of tools (a filter field, the ignored files toggle, Collapse all folders), then the working folder: the project's name for the checkout, its path from the project for a worktree inside it. Folders open one level at a time, each listed through the host's `useListFolder` when it opens; what git ignores shows only while the toggle (or the command `files.toggleIgnored`) is on. The tree is the host's `Tree`, virtualised, with VS Code's explorer keys and selection.

It stays up to date with the disk: `useFolderChanges` reports each batch of changed paths, and the open folders that hold one are listed again, parents first, forgetting what was under a folder that is gone (`src/rules/folder-tree.ts`). Rows take their git status from `useGitStatus`, a folder the most pressing status of the files under it (`src/rules/git-marks.ts`); when git cannot read them, `useGitStatus` also gives the message, shown above the tree with Retry. The file `useFileOnScreen` names is revealed: its folders open and the `Tree`'s `revealId` selects it. Text in the filter swaps the tree for the files of `useListFiles` whose name holds it, under their folders, all open (`src/rules/filter-rows.ts`).

Go to file, in the `window.overlay` slot (contribution `files/goToFile`): the command `files.goToFile` (⌘P) opens the host's `QuickPick` over the working folder's files, ranked by `src/rules/rank-files.ts` from an index built once per listing (`useFileList` keeps the listing shown when a new one says the same, `src/rules/keep-listing.ts`), and opens the chosen one with `useOpenFile`.

The button at the end of the tools row, and the command `files.collapseAll`, close every open folder of the tree on screen. What each session had open, and its filter, is kept while the plugin is active, and listed again when the session comes back on screen. States: no session on screen, an empty folder, a deleted working folder, a listing that fails (the host's message, with Retry when it can work), and a filter or a Go to file with no match. The command `files.show` (⌘2) opens the tab. The rows come from `src/rules/tree-rows.ts`, the folder's label from `src/rules/folder-label.ts`.
