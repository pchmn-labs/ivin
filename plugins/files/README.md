# files

The Files tab of the sidebar, in the `sidebar.panel` slot (contribution `files/panel`, titled "Files"): a tree of the working folder of the session on screen, which follows it when another session comes on screen. Above the tree, the working folder: the project's name for the checkout, its path from the project for a worktree inside it. Folders open one level at a time, each listed through the host's `useListFolder` when it opens, so what git ignores never shows; the tree is the host's `Tree`, virtualised, with VS Code's explorer keys and selection. The command `files.collapseAll` closes every open folder. What each session had open is kept while the plugin is active, and listed again when the session comes back on screen. States: no session on screen, an empty folder, a deleted working folder, and a listing that fails (the host's message, with Retry when it can work). The command `files.show` (⌘2) opens the tab. The rows come from `rules/tree-rows.ts`, the folder's label from `rules/folder-label.ts`.
