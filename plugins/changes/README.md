# changes

The Changes tab of the sidebar, in the `sidebar.panel` slot (contribution `changes/panel`, titled "Changes", with the number of uncommitted changes, then of committed ones when there are some, after its name through the `badge` option). One host `ChangeList` with two groups: Uncommitted, the working folder's changes against HEAD, untracked files included, through `useChanges`; and Committed, what the commits of the session's branch changed since it left `origin/<default branch>`, through `useCommittedChanges`. The host lists both again after each change on disk. It follows the session on screen.

Each change is a row of the `ChangeList` (`src/rules/change-items.ts`). A click or Enter opens its diff beside the chat with `useOpenDiff` (`useOpenCommittedDiff` in Committed), and the row of the diff on screen (`useDiffOnScreen`, `useCommittedDiffOnScreen`) is selected. An uncommitted row's Discard button or Backspace, and the Uncommitted heading's Discard all button or ⌘Backspace, ask in a `Dialog` (`src/rules/discard-text.ts`), then run `useDiscardChange` or `useDiscardAllChanges`; a failure shows under the row or the heading.

States: no session on screen, no `origin` remote, no default branch on record, or no commit shared with it (Committed only), a deleted working folder, a working folder outside a git repository, no changes, and a listing git fails (the host's message, git's output under it, and Retry). The command `changes.show` (⌘3) opens the tab.
