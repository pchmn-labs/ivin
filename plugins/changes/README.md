# changes

The Changes tab of the sidebar, in the `sidebar.panel` slot (contribution `changes/panel`, titled "Changes", with the number of uncommitted changes, then of the branch's changes when it has some, after its name through the `badge` option). Two lists, each a `ChangeList` with a heading: the uncommitted changes of the working folder of the session on screen, against HEAD, untracked files included, through the host's `useChanges`; then the branch's changes since its merge base with `origin/<default branch>`, through `useBranchChanges`. The host lists both again after each change on disk. It follows the session on screen.

Each change is a row of the host's `ChangeList`: its status letter, its name, its folder and its added and deleted line counts (`src/rules/change-items.ts`). A click or Enter opens its diff beside the chat with `useOpenDiff` (`useOpenBranchDiff` in the branch list), and the row of the diff on screen (`useDiffOnScreen`, `useBranchDiffOnScreen`) is selected. An uncommitted row's Discard button asks in a `Dialog` (`src/rules/discard-text.ts`), then runs `useDiscardChange`; a failure shows under the row. The row's Open file button opens the file itself with `useOpenFile`; a deleted file has none.

States: no session on screen, no `origin` remote, no default branch on record, or no commit shared with it (the branch list only), a deleted working folder, a working folder outside a git repository, no changes, and a listing git fails (the host's message, git's output under it, and Retry). The command `changes.show` (⌘3) opens the tab.
