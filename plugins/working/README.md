# working

Lists, in the `sidebar.bottom` slot (contribution `working/panel`), every session of an open project that runs or waits for an approval, except the session on screen; the current project's sessions included, so the panel stays the one place to watch them when the sidebar shows something else. Sessions waiting for an approval come under "Needs you", running ones under "Running"; each group goes project by project, longest in its status first. A row shows the session's status, title, project and how long it has been in that status. A waiting row also shows the command the approval asks about (the whole of it in a tooltip) and answers it with Allow or Deny through `useAnswerApproval`, without opening the session; a failed answer shows the host's message under the buttons, with Retry when the host says a second try can work. Clicking a row selects its project and opens its tab, where the approval sheet takes the keyboard. The panel folds, and is absent when no session matches. Which sessions are listed, and in what order, is in `src/rules/working-sessions.ts`. The `working-panel`, `working-session` and `working-command` test ids are read by tests.
